# Wealthy Reports prototypes

Two interactive alternatives for simplifying report generation:

- **Variation 1:** client selection with a persistent 67/33 configuration panel.
- **Variation 2:** full-page client selection with a completion modal.

[Open the prototypes](https://ayush307k.github.io/wealthy-reports-prototypes/)

These are standalone review prototypes using fictional client data. Email, scheduling, and report processing are simulated; no production services are connected. See `coverage.html` for supported flows and implementation limitations.

## Run locally

Run `python3 -m http.server 8000` in this directory and open `http://localhost:8000`.

Built with plain HTML, CSS, and JavaScript. GitHub Pages serves the root of the `main` branch.
